# Tamilarasan K — Developer Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — dark theme and responsive styling
- `script.js` — mobile navigation and dynamic copyright year

## Run locally
1. Extract the ZIP file.
2. Open the `portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Before publishing
- Replace `your-email@example.com` with your email.
- Update GitHub and LinkedIn profile links.
- Replace sample project links with your real repositories.
- Only list skills and projects that accurately represent your experience.

## Deploy
You can publish this static site using GitHub Pages or Netlify.
